## 1. Shared object shapes

### Report
```json
{
  "id": "R-1045",
  "siteId": "moran",
  "siteName": "Moran Field",
  "reportType": "near_miss",
  "text": "Fitter opened pump casing without lockout while motor was still connected...",
  "language": "en",
  "reportedAt": "2026-08-14T09:30:00.000Z",
  "activity": "Pump maintenance",
  "location": "Well pad 3",
  "reportedBy": "K. Baruah",
  "classification": "SIF",
  "sifProbability": 0.91,
  "confidence": 0.88,
  "highlightedPhrases": [{ "text": "without lockout", "start": 22, "end": 37, "weight": 0.42 }],
  "lifeSavingRules": [{ "rule": "energy_isolation", "confidence": 0.93 }],
  "barrierFailureType": "isolation",
  "potentialSeverity": "fatal",
  "status": "auto",
  "review": null,
  "createdAt": "2026-08-14T09:31:00.000Z"
}
```
- `status`: `auto` | `reviewed`
- `review` (when reviewed):
```json
{ "by": "userId", "byName": "A. Bora", "at": "ISO", "originalClassification": "NON_SIF",
  "newClassification": "SIF", "newRules": ["energy_isolation"], "newBarrierFailureType": "isolation", "note": "text" }
```
- `id` format: `R-<number>`, generated by the server if not supplied.

### User
```json
{ "id": "u1", "name": "A. Bora", "email": "a@oil.in", "role": "hse_officer", "siteId": null, "active": true }
```
`siteId` is required only for `site_supervisor`.

## 2. Node REST API (client → server). Base: `/api`

Auth = JWT in httpOnly cookie `sifguard_token`. Client must send `credentials: "include"`.
CORS: allow origin `http://localhost:5173` (and the Vercel URL via env).

### Auth
| Method | Path | Body | Response |
|---|---|---|---|
| POST | `/auth/login` | `{email, password}` | `{user}` + sets cookie |
| POST | `/auth/logout` | – | `{ok:true}` |
| GET | `/auth/me` | – | `{user}` or 401 |
| POST | `/auth/register` (admin) | `{name,email,password,role,siteId?}` | `{user}` |

### Reports
| Method | Path | Notes |
|---|---|---|
| POST | `/reports/upload` (admin, hse_officer) | multipart field `file` (.csv/.xlsx). Response: `{batchId, total, inserted, sifCount, skipped, errors:[{row,message}]}` |
| GET | `/reports` | query: `siteId, classification, rule, barrier, from, to, q, status, page=1, limit=20`. Response: `{items:[Report], total, page, limit}` |
| GET | `/reports/:id` | `{report, audit:[{at,byName,action,detail}]}` |
| PATCH | `/reports/:id/review` (admin, hse_officer) | body `{newClassification, newRules?[], newBarrierFailureType?, note?}` → `{report}` (writes audit entry, stores correction for retraining) |

**Upload file columns** (header row, case-insensitive):
`report_id` (optional), `site` (id or name), `report_type`, `reported_at` (ISO or DD/MM/YYYY), `activity`, `location`, `reported_by` (optional), `text` (required).

### Dashboard (all respect role/site scoping)
| GET | Response |
|---|---|
| `/dashboard/summary` | `{totalReports, sifCount, sifPercent, reviewedCount, lastUpdated}` |
| `/dashboard/sites` | `{items:[{siteId, siteName, totalReports, sifCount, sifDensity, rank, topRule, topBarrier}]}` sorted by `sifDensity` desc (`sifDensity = sifCount/totalReports`) |
| `/dashboard/patterns` | `{items:[{id, label, activity, location, barrierFailureType, rule, count, siteIds:[], exampleReportIds:[]}]}` (from ML `/cluster`, cached) |
| `/dashboard/trends?from&to&siteId` | `{daily:[{date:"YYYY-MM-DD", total, flagged}]}` |
| `/dashboard/rules` | `{items:[{rule, count}]}` (Life-Saving Rule distribution) |

### Export (admin, hse_officer)
`GET /export?format=pdf|xlsx&from=YYYY-MM-DD&to=YYYY-MM-DD` → file download (`Content-Disposition: attachment`).
Content: weekly intervention-priority list — sites ranked by SIF density, top patterns, top SIF reports.

### Admin (admin only)
| Method | Path | Notes |
|---|---|---|
| GET | `/admin/users` | `{items:[User]}` |
| PATCH | `/admin/users/:id` | `{role?, siteId?, active?}` |
| GET | `/admin/model` | proxy of ML `/metrics` + `{pendingCorrections}` |
| POST | `/admin/retrain` | sends corrections to ML `/retrain`; response `{status, trainedOn, metrics}` |

### Notifications
`GET /notifications` → `{items:[{id, reportId, siteId, message, sifProbability, createdAt, read}]}`; `PATCH /notifications/:id/read`.
Created automatically when a new report has `sifProbability >= NOTIFY_THRESHOLD` (env, default `0.85`).

## 3. ML service API (server → ml-service ONLY; never called by the browser)

Base `http://localhost:8000`. Batch-first so uploads are fast.

### `GET /health` → `{status:"ok", modelVersion:"v1"}`

### `POST /classify`
```json
// request
{ "reports": [ { "id": "R-1045", "text": "...", "language": "en" } ] }
// response
{ "results": [ {
  "id": "R-1045",
  "classification": "SIF",
  "sifProbability": 0.91,
  "confidence": 0.88,
  "highlightedPhrases": [ { "text": "without lockout", "start": 22, "end": 37, "weight": 0.42 } ],
  "potentialSeverity": "fatal",
  "barrierFailureType": "isolation",
  "entities": { "activity": "Pump maintenance", "location": "Well pad 3", "equipment": "pump" }
} ] }
```
`start`/`end` are character offsets into the original `text`. If `language` != `en`, translate first, but offsets must still refer to the original text (or return empty `highlightedPhrases`).

### `POST /tag-rules`
```json
{ "reports": [ { "id": "R-1045", "text": "..." } ] }
→ { "results": [ { "id": "R-1045", "lifeSavingRules": [ { "rule": "energy_isolation", "confidence": 0.93 } ] } ] }
```
Multi-label, only rules with confidence ≥ 0.4, max 3, sorted desc. Empty array allowed.

### `POST /cluster`
```json
{ "reports": [ { "id": "R-1045", "text": "...", "activity": "...", "location": "...", "barrierFailureType": "isolation", "rules": ["energy_isolation"], "siteId": "moran" } ] }
→ { "clusters": [ { "id": "C1", "label": "Isolation failure during pump maintenance", "activity": "Pump maintenance",
      "location": "Well pad", "barrierFailureType": "isolation", "rule": "energy_isolation",
      "count": 7, "siteIds": ["moran","duliajan"], "reportIds": ["R-1045"] } ] }
```

### `POST /retrain`
```json
{ "corrections": [ { "text": "...", "classification": "SIF", "rules": ["hot_work"], "barrierFailureType": "procedure" } ] }
→ { "status": "completed", "trainedOn": 42, "modelVersion": "v2", "metrics": { "accuracy": 0.9, "f1": 0.88 } }
```

### `GET /metrics`
`{ "modelVersion":"v2", "accuracy":0.9, "precision":0.89, "recall":0.91, "f1":0.9, "lastTrainedAt":"ISO", "trainingSamples":1200 }`

**Timeout rules:** Node waits up to 60s for `/classify` batches (send 32 reports per call). If ML is down, return `ML_UNAVAILABLE`; do NOT crash the upload — mark rows `skipped`.
